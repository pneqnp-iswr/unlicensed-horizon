# unlicensed-horizon-client v0.7 — инструкция

Этот проект запускает открытый движок Horizon с локальным ником, без входа Microsoft в нашем лаунчере. Он **не содержит игровые файлы Minecraft** и **не является готовой игрой без лицензии**. Для запуска требуется полный комплект ресурсов Horizon 26.3, созданный из законно полученной копии Java Edition.

## Windows

1. Распакуй архив и открой `START-WINDOWS.bat`.
2. Введи ник. Для главного меню оставь поля **World** и **Server** пустыми.
3. **Install Engine** — установит официальный исполняемый файл Horizon с проверкой цифровой подписи.
4. **Find Prepared Data** / **Browse** — выбери папку подготовленных игровых ресурсов `26.3`.
5. **Audit Resources** — проверка обязательных файлов подготовленного Horizon (не гарантирует работоспособность игры).
6. **Check Setup**, затем **PLAY**. Если ошибка, **View Game Logs**.

Для локального сервера с выключенным online-mode впиши адрес `localhost:25565` в **Server**, оставив **World** пустым. Ник на таких серверах не защищён от подмены. Сервера с `online-mode=true` требуют настоящую авторизацию.

## Важное исправление сохранений v0.3

В версиях 0.1–0.2 миры могли сохраняться в папке установленного движка, а не рядом с пользовательскими настройками. Открой CMD в папке проекта и выполни:

```cmd
unlicensed-horizon-client.exe legacy-worlds
```

Если старые миры найдены, при выключенной игре скопируй папки миров из `Old engine saves` в `Current saves`. Не удаляй оригиналы до проверки мира.

## Статус

Автономное имя и безопасное управление клиентом реализованы. Для полностью независимой игры без Minecraft требуется заново разработать/легально получить совместимые реестры, игровые данные и графические ресурсы. На настоящем Windows ПК запуск Horizon пока не проверен.


## Новое в v0.5: собственные игровые данные и структурный анализ

В GUI нажми **4. Create Original Content Lab**, затем **5. Inspect Original Lab Contracts**. Аналогичные команды для CMD:

```cmd
unlicensed-horizon-client.exe lab-init
unlicensed-horizon-client.exe lab-contract "%APPDATA%\unlicensed-horizon-client\open-content-lab-v0.7"
unlicensed-horizon-client.exe lab-audit "%APPDATA%\unlicensed-horizon-client\open-content-lab-v0.7"
```

Генерируется **80 файлов + контрольный манифест**, включая 19 состояний блоков (12 дополнительных для галереи Horizon), 18 моделей и 36 PNG-текстур. Все текстуры созданы алгоритмически и не копируются из Minecraft. Проверяются индексы реестра, обязательные теги, модели, ссылки на текстуры и сами PNG. Порча файла обнаруживается даже при обновлении его SHA-256 в манифесте.

**Важно:** это пока не полноценная игра. Проверка выполняется отдельным Go-кодом, а не настоящим Rust-загрузчиком Horizon. Оригинальные ресурсы остаются экспериментальными и не проходят `doctor`/`play`. Запуск без файлов Minecraft **не подтверждён**.

## Версия 0.6: реальный тест загрузчика

В новой лаборатории **82 самостоятельно созданных файла + манифест**, включая экспериментальные таблицы времени суток и параметров измерения. Тест данных по-прежнему не равен запуску игры.

После установки Horizon и генерации нового набора через **4. Create Original Content Lab** можно нажать **6. Run isolated Horizon laboratory probe**, либо открыть `PROBE-LAB-WINDOWS.bat`. Это отдельный диагностический запуск: копия данных идёт в изолированную папку, используется отдельный мир `UHC_LabProbe`, а процесс ограничен 20 секундами (с дополнительным ограничением со стороны лаунчера). Никакие настоящие сохранения или Microsoft-сессии не используются.

Результаты ищи в `%APPDATA%\unlicensed-horizon-client\probe-reports\probe-v0.7-*\`: `process.log`, `probe-result.json` и, если Horizon успел его создать, `horizon-smoke.json`. **Отсутствие ошибки ещё не доказывает, что игра готова**. На нашей машине в этот цикл настоящий Horizon не запускался.
